# KAVOD AUTO DETAILING — Landing Page

Landing page de una sola página con arquitectura **Page113** (vistas múltiples
tipo SPA + long-scroll interno), construida con **HTML5 semántico**, **Tailwind
CSS (JIT compilado)** y **JavaScript vanilla**. Diseño premium inspirado en la
estética de `diamonddetailingmiami.com` (hero asimétrico con formulario,
secciones alternadas, grid de paquetes, testimonios, FAQ y CTA final).

---

## 🚀 Requisitos

- Node.js **v16+**
- npm **v7+**

---

## 🛠️ Instalación y desarrollo

```bash
git clone https://github.com/tu-usuario/kavod-landing.git
cd kavod-landing
npm install
npm run dev      # compila Tailwind en watch mode
